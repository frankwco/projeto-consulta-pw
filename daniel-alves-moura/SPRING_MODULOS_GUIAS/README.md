# Guias de configuração dos módulos Spring

Há três versões do mesmo material, pensadas para necessidades diferentes:

| Arquivo | Uso recomendado |
| --- | --- |
| `01_SPRING_MODULOS_RESUMO_RAPIDO.md` | Consulta rápida durante prova; configuração mínima por módulo. |
| `02_SPRING_MODULOS_PASSO_A_PASSO.md` | Implementação prática, erros comuns e adaptação. |
| `03_SPRING_MODULOS_REFERENCIA_APROFUNDADA.md` | Estudo aprofundado: funcionamento, armadilhas, arquitetura e decisões. |

## Ordem sugerida de leitura

1. Comece pela versão rápida para localizar o módulo.
2. Abra a versão passo a passo para implementar.
3. Use a versão aprofundada quando aparecer erro, dúvida de arquitetura ou incompatibilidade de versão.

Os exemplos principais seguem estilo compatível com Spring Boot 3.x + Java 21 e incluem observações de compatibilidade com versões mais novas quando necessário.
