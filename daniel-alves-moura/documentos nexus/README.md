# NexusERP — Documentação de consulta para prova

Este pacote contém quatro guias em **Markdown**, preparados para leitura no GitHub, VS Code ou qualquer editor de texto.

## Arquivos

- `01_NexusERP_Implementacao_Prática.md` — implementação do projeto, camada por camada, com exemplos do código.
- `02_Spring_Boot_Modulos_Configuração_Prática.md` — configuração prática dos módulos do Spring Boot.
- `03_React_API_Frontend_Prático.md` — React, Vite, Axios, JWT, rotas, formulários e integração com API.
- `04_Comandos_Maven_React_VSCode.md` — comandos essenciais e diagnóstico rápido.

Cada guia começa com um **índice alfabético** para localizar rapidamente o assunto durante a prova. Os blocos de código foram preservados com syntax highlighting compatível com GitHub Markdown.
